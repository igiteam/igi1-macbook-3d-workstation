Pi 3B+ and Pi 4 have no PCIe, so NVMe options are USB-based.

Pi 5 uses the Geekworm X1004 HAT (PCIe 2.0 only, max ~400MB/s shared).

Adafruit 16×2 LCD + Keypad Kit is a DIY solder kit — 5 tactile buttons (Up/Down/Left/Right/Select) + 16×2 character LCD, connected via I2C on 2 GPIO pins.

Note: The LCD sits on the 40-pin GPIO header, so on Pi 5 builds it stacks above the NVMe HAT. Check clearance and ribbon cable routing before assembling.
