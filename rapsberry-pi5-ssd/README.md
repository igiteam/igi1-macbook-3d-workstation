✅ Why "All New" Is a Good Choice

No surprises. Used eBay Pi bundles sometimes arrive with:
    Missing screws or standoffs
    Bent GPIO pins
    SD cards that were already written many times
    Coolers that have been running hot for years
    Cases with stripped screw holes

Buying new eliminates all of that. You know every part's history.

Warranty. Amazon returns are trivial. If the Pi 5 is DOA, you send it back. If the X1004 has a bad PCIe connector, you send it back. With eBay private sellers, you're often stuck.
